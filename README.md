# WARDOGS 迫击炮弹道计算机

AstrBot 插件：通过 `/wdbc` 计算《WARDOGS》炮位到目标位的方位角、方位密位、距离（M）和 L81 射程密位（MIL）。坐标每 1 单位等于 100 米。

## 用法

```text
/wdbc x64.85, y71.98 x74.85, y61.13
/wdbc x64.85,y71.98 y74.85x61.13
/wdbc 64.85 71.98 74.85,61.13
```

第一次使用请提供炮位和目标位两组坐标；炮位将按“平台 + 用户”隔离缓存 105 分钟。之后只传目标位即可。方位以地图正北为 0°，顺时针增加，并同时输出 6400 制方位密位。L81 射程密位基于社区射表，在 132–684 M 内线性插值；超出范围会明确提示，且未进行高差修正。

插件内置 `wardogs-ballistic` Skill。启用后，模型在收到 WARDOGS 地图截图、迫击炮或坐标问题时，会识别场景并引导/调用 `/wdbc` 得到准确结果。

## 开发

无第三方运行时依赖。运行测试：

```bash
python -m pytest
```
