# WARDOGS 迫击炮弹道计算

当用户需要《WARDOGS》迫击炮的方向、距离或密位时，优先从消息或图片中识别地图坐标。游戏标准格式为 `x64.85, y71.98`，也可能是 `y74.85x61.13`、`64.85 71.98`。无轴标记的数字按 `x y` 顺序理解。每 1 坐标单位为 100 米。

使用机器人指令执行实际计算，不要自行臆测距离：

- 同时有炮位和目标位：`/wdbc <炮位> <目标位>`。这会更新该用户的炮位缓存 105 分钟。
- 仅有目标位：`/wdbc <目标位>`。仅当用户已设置且未过期的炮位时可计算。

示例：

```text
/wdbc x64.85, y71.98 x74.85, y61.13
/wdbc x64.85,y71.98 y74.85x61.13
/wdbc 64.85 71.98 74.85,61.13
```

若 Agent 运行环境允许执行 Skill 脚本，且从图片或文本中可靠提取到两组坐标，可运行 `scripts/calculate.py '<炮位>' '<目标位>'` 得到方位角、6400 制方位密位和米制距离。需要用户的缓存炮位或 L81 射程密位时，仍应使用 `/wdbc`，因为该命令维护该用户独立的 105 分钟缓存并应用完整射表。

结果中的方位密位是 6400 MIL 一周制；`射程密位（L81）` 是 L81 迫击炮瞄具的社区射表值，仅在 132–684 M 内有效且不含高差修正。若截图中无法可靠读出两个坐标，说明需要炮位与目标位各一组清晰坐标，并请用户复制游戏标记的标准文本。不要将地图格、地名或像素位置当作精确坐标。
